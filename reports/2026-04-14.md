## Research

### TypeScript Research

Research agent ran for 486s / 104 turns and made meaningful changes:

- **New Known Issue added — KI #50**: `outputFormat` with nested object schemas returns `subtype: 'success'` but `structured_output` is absent. When the model wraps JSON in markdown fences instead of returning raw JSON (more common with complex nested schemas), the SDK's structured output extractor fails and returns `undefined` silently. Workaround: guard on `structured_output` presence and fall back to parsing from `result` string. Related to v0.2.105 fix for `error_max_structured_output_retries` (separate issue).
- **KI #38 updated as fixed**: MCP server zombie process accumulation marked fixed in v0.2.94. Description updated from active workaround to "Fixed: upgrade to v0.2.94+".
- **Changelog expanded**: Added entries for v0.2.89 (`listSubagents()`, `getSubagentMessages()`), v0.2.91 (`'auto'` PermissionMode, `sandbox.failIfUnavailable` default change), v0.2.92 (file-based agents discovery regression fixed), v0.2.94 (MCP cleanup fix, `getContextUsage()` agents breakdown fix), v0.2.105 (structured output retry fix, `system/memory_recall` event).
- **API references updated**: `getContextUsage()` and `SDKAPIRetryMessage` version labels updated to v0.2.107.
